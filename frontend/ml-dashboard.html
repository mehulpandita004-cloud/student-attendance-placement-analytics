College Viva Examiner Defense Cheatsheet

Clear, technically sound explanations prepared for viva defense regarding algorithms, metrics, and methodology.

🎯 Q1: Why did you compare Logistic Regression, Decision Tree, and Random Forest?
Answer: We wanted to benchmark a linear parametric model (Logistic Regression) against an interpretable tree model (Decision Tree) and an ensemble bagging model (Random Forest). Logistic Regression provides baseline calibrated probabilities, while Random Forest reduces variance and captures complex interactions (e.g., how Backlogs interact with CGPA) without overfitting.
🎯 Q2: Why is F1-score more important than simple Accuracy for student defaulter classification?
Answer: Accuracy is deceptive in imbalanced cohorts. If 80% of students attend regularly, a naive classifier predicting everyone as 'Low Risk' achieves 80% accuracy while failing 100% of at-risk defaulters. Macro F1-score calculates the harmonic mean of precision and recall equally across all classes, penalizing models that overlook minority at-risk cohorts.
🎯 Q3: What does the Confusion Matrix tell us in this system?
Answer: The rows represent actual ground truth student classes, while columns represent model predictions. Values along the diagonal (top-left to bottom-right) are True Positives. Off-diagonal cells reveal error types: False Positives (over-flagging a safe student) versus False Negatives (missing a true defaulter, which is academically dangerous).
🎯 Q4: Why use joblib for model serialization instead of Python pickle?
Answer: joblib is heavily optimized for scikit-learn models containing large NumPy numeric arrays (such as tree estimators and weight vectors), yielding faster serialization and lower memory consumption compared to vanilla pickle.
